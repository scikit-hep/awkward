.. py:function:: ak.is_categorical(array)

   Returns True if the array is categorical.

   If the ``array`` is categorical (contains :py:obj:`ak.contents.IndexedArray` or
   :py:obj:`ak.contents.IndexedOptionArray` labeled with parameter
   ``"__array__" = "categorical"``), then this function returns True; otherwise,
   it returns False.

   See also :py:obj:`ak.categories`, :py:obj:`ak.str.to_categorical`, :py:obj:`ak.from_categorical`.

   :param array: Array-like data (anything :py:obj:`ak.to_layout` recognizes).

   :returns: True if ``array`` is categorical, False otherwise.
