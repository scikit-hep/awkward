.. py:function:: ak.materialized(array, highlevel=True, behavior=None)


    :param array: The possibly virtual array to ensure is materialized.
    :param highlevel: If True, return an :py:obj:`ak.Array`; otherwise, return
                  a low-level :py:obj:`ak.layout.Content` subclass.
    :type highlevel: bool
    :param behavior: Custom :py:obj:`ak.behavior` for the output array, if
                 high-level.
    :type behavior: None or dict

Returns ````array```` with all virtual array nodes fully materialized.

See also :py:obj:`ak.virtual`.
