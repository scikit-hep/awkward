ak._ext.ArrayBuilder#

The low-level ArrayBuilder that builds ak.contents.Content arrays. This object is wrapped by ak.ArrayBuilder.

(Method names in the high-level interface have been changed to include underscores after “begin” and “end,” but that hasn’t happened in the low-level interface, yet or possibly at all.)
