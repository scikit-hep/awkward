.. py:function:: ak.to_jax(array)


   Converts an Awkward Array into a JAX Array, if possible.

   If the data are numerical and regular (nested lists have equal lengths in
   each dimension, as described by the :py:obj:`ak.Array.type`), they can be losslessly
   converted to a JAX array and this function returns without an error.

   Otherwise, the function raises an error.

   If ``array`` is a scalar, it is converted into a JAX scalar.

   See also :py:obj:`ak.from_jax` and :py:obj:`ak.to_numpy`.

   :param array: Array-like data (anything :py:obj:`ak.to_layout` recognizes).

   :returns: A JAX array with the same data as ``array``, if the conversion is possible.
