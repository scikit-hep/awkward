Detailed Description

template<typename PRIMITIVE, typename BUILDER>
class awkward::LayoutBuilder::Indexed< PRIMITIVE, BUILDER >

Builds an IndexedArray which consists of an index buffer. It is a general-purpose tool for changing the order of and/or duplicating some content.

The index values can be 64-bit signed integers int64, 32-bit signed integers int32 or 32-bit unsigned integers uint32.

Template Parameters
PRIMITIVEThe type of index buffer.
BUILDERThe type of builder content.
