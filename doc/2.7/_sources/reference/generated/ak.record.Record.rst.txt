.. py:class:: ak.record.Record(self, array, at)

Represents a single value from a :py:obj:`ak.contents.RecordArray`.

As this is a columnar representation, the Record contains a
:py:obj:`ak.layout.RecordArray`, rather than the other way around.
Its two fields are

* ``array``: the :py:obj:`ak.layout.RecordArray` and
* ``at``: the index posiion where this Record is found.

The Record shares a reference with its :py:obj:`ak.layout.RecordArray`;
it is not a copy.
