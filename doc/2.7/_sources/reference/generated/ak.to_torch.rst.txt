.. py:function:: ak.to_torch(array)


    :param array: Array-like data. May be a high level :py:obj:`ak.Array`,
              or low-level :py:obj:`ak.contents.ListOffsetArray`, :py:obj:`ak.contents.ListArray`,
              :py:obj:`ak.contents.RegularArray`, :py:obj:`ak.contents.NumpyArray`

Converts ``array`` (only ListOffsetArray, ListArray, RegularArray and NumpyArray data types supported)
into a PyTorch Tensor, if possible.

If ``array`` contains any other data types (RecordArray for example) the function raises a TypeError.
