.. py:function:: ak.materialize(array, highlevel=True, behavior=None, attrs=None)


    :param array: Array-like data (either an :py:obj:`ak.Array` or an :py:obj:`ak.contents.Content`).
              An array that may contain virtual buffers to be materialized.
    :param highlevel: If True, return an :py:obj:`ak.Array`;
                  otherwise, return a low-level :py:obj:`ak.contents.Content` subclass.
    :type highlevel: bool, default is True
    :param behavior: Custom :py:obj:`ak.behavior` for the output array, if
                 high-level.
    :type behavior: None or dict
    :param attrs: Custom attributes for the output array, if
              high-level.
    :type attrs: None or dict

Traverses the input array and materializes any virtual buffers.
If the input array is not an :py:obj:`ak.Array` or an :py:obj:`ak.contents.Content`,
an error will be raised.
The buffers of the returned array are no longer ``VirtualNDArray`` objects even if there were any.
They will become one of ``numpy.ndarray``, ``cupy.ndarray``, or ``jax.numpy.ndarray`` objects,
depending on the array's backend.
